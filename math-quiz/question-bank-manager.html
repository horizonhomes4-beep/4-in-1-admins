Upload / replace questions

Use the Excel template or a previously downloaded class workbook. Select the target class above; imported questions will be assigned to that class.

Replacement affects only the selected class. Questions assigned to other classes remain there. Duplicate questions in the workbook will be skipped.

Move questions to this class

Move an entire question bank from another class into the selected class. This removes the old class assignment before assigning the questions to the selected class, preventing the same question records from appearing in both classes.

Questions are moved, not copied. Existing question records are reused, so no duplicate records are created.

Delete all questions for this class

This removes the selected class's question bank only. Questions assigned to other classes and student results are not deleted.
